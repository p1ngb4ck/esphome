# binary_storage

EEPROM, FRAM, MRAM and SPI flash chips on I2C, SPI and 1-Wire, partitions of the chip's own flash and NVS
partitions as storages of the storage interface - raw, as LittleFS file systems, as key-value stores or as NVS.

Every option and an example for every device type: `CONFIGURATION.md` of
[esphome-storage-drivers](https://github.com/p1ngb4ck/esphome-storage-drivers/blob/main/CONFIGURATION.md#binary_storage).
